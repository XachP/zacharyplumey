# zacharyplumey.com

Personal site for Zachary Plumey — IT support and front-end / full-stack development. Chicago area or remote. Open to full-time roles and freelance work.

## Editing
It's a single static file: **`index.html`** (HTML + CSS inline, no build step).
- Add/swap work items: duplicate a `.card` block in the `#work` section and change the `href`, title, and text.
- Résumé: replace `Zachary-Plumey-Resume.pdf` at the repo root. The nav, hero, and footer link to `/Zachary-Plumey-Resume.pdf`.
- Push to `main` → Render auto-deploys → live on zacharyplumey.com.
