# zacharyplumey.com

Personal site for Zachary Plumey — front-end and full-stack development, plus IT support. Open to full-time roles and freelance work.

## Editing
It's a single static file: **`index.html`** (HTML + CSS inline, no build step).
- Add/swap work items: duplicate a `.card` block in the `#work` section and change the `href`, title, and text.
- Résumé: replace `Zachary_Plumey_Resume.pdf` at the repo root. The nav and footer link to `/Zachary_Plumey_Resume.pdf`.
- Push to `main` → Render auto-deploys → live on zacharyplumey.com.
